# 记忆复核（38.1；38.2 加了看图抽查；38.3 加了给她的话打分）

白天 Flash 每 40 条整理一次，记下的事算**临时**；每天 18:00 由 Claude 复核一次，复核过的才算数。
复核不调 API：Claude 读导出的聊天，写一张**操作单**，由 `scripts/mem_review.py apply` 校验后写库。

## 每次怎么做（定时任务照这个跑）

1. `python scripts/mem_review.py status`：看上次复核到哪、还剩几条。
2. `python scripts/mem_review.py export`：导出上次之后的聊天（最多 1500 条，`more: true` 就分几次做），会同时生成一份 `.txt` 方便读。
3. 从头到尾读一遍聊天，对照“现在记着的事”和画像，写操作单（格式见下）。
4. `python scripts/mem_review.py apply 单子.json --dry`：先试跑，被拒的看原因改掉。
5. `python scripts/mem_review.py apply 单子.json`：正式写（自动备份到 `data/backup/before-mem-review-*.db`，留最近 14 份）。
6. 还有 `more` 就回到第 2 步；最后跑 `check`，看临时的还剩几条、有没有重复。
7. 写错了：`python scripts/mem_review.py undo RUN编号`，整次退回。

## 什么值得记（事实）

记**以后聊天时用得上、过几天还成立或还会被提起**的事：

| 记 | 不记 |
|---|---|
| 身份和长期状态：在读什么、在哪实习、备考什么、住哪个城市（到城市为止） | 当下的动作和情绪：“刚睡醒”“好困”“在地铁上”（除非连着几天、成了近况） |
| 有日子的事：考试、面试、出发、生日、比赛门票、截止日 | 闲聊里的一句评论：“这集神了”“jdg 钱多” |
| 稳定的喜好 / 讨厌 / 习惯 / 立场：主队、忌口、爱喝什么、对某事的态度 | 对新闻、比赛、模型的一次性点评（除非是他一贯的立场） |
| 做成的事、作品、经历：做了什么项目、去了哪玩、买了什么大件 | 转述网上的消息（那是新闻，不是他的事） |
| 人和人的关系：谁和谁是搭档、谁请谁吃饭、谁送谁礼物 | 玩笑、互损、反话、假设、“要是……” |
| 她（-1）自己说过的、以后要前后一致的事：她的喜好、立场、对群友的态度、答应过的事 | 她说过的一次性查资料结论（价格、比分、新闻细节） |

**重要度**：3 = 身份、长期状态、关系、有日子的大事（考试、生日、面试）；2 = 一般喜好、近况、做过的事；1 = 小事（可以记，但一周后就淡）。
拿不准值不值得记就别记——画像的“近况”“记得的事”会兜住。

## 来源和原话

- 每条新记的事都要带**原话**：`msg` 是消息编号，`quote` 是从那条消息里**逐字**抄的一小段（标点空格可以不管）。对不上的一律被拒。
- `source`：`self` 本人说自己（原话必须是他说的）；`other` 别人说他、转述；`guess` 从话里推出来的（只猜过一次的不会拿来用）；`said` 她自己说的。
- 她自己的事：`about: -1`，原话必须是她说的，kind 用 `experience`（她的事 / 喜好 / 答应的）或 `opinion`（她的看法立场）。
- 群里的事：`about: 0`，kind 用 `event`（发生过的群事件）或 `plan`（大家约好的）。

## 时间

- `until`：只在一段时间成立的（“这周在赶论文”“期末周”），写到哪天为止（YYYY-MM-DD）；过了就自动不用。
- `when`：这件事是哪天（考试、面试、出发、生日）；这一周内要发生的会在召回时往前排。
- `attr`：单值属性的名字，同一个人同一个 attr 新记一条会自动替掉旧的。常用：`school` `major` `job` `intern` `city` `exam` `grade` `partner` `birthday` `team`（主队） `device`。

## 处理已经记着的事

- 对的：`keep`（可以顺手改措辞 `text`、改 `importance` / `until` / `when` / `attr` / `source` / `about`）。
- 不该记的：`drop`，`why` 必须是 `玩笑 / 琐碎 / 记错 / 重复 / 过期 / 隐私 / 不是他的事 / 被取代` 之一。
  `玩笑 / 记错 / 隐私 / 不是他的事` 可以加 `"forget": true`：删掉并留指纹，白天的整理以后不会再学回来。
- 改口了（换实习、考完了、分手了）：新记一条，`replaces` 写旧的编号（或用同一个 `attr`），旧的会标成“以前是”。
- 重复的几条：留最好的一条 `keep`，其余 `drop`（why 重复）。

## 群笔记、她自己的笔记、画像

- `group_notes`：这个群最近的事和梗，**最多 10 行**，每行带日子，过时的删掉。会整份替换，白天新记的那几行合进来或丢掉。
- `norms`：群里不成文的规矩，最多 6 行，没把握不写。
- `self_notes`：她说过的关于自己的事（要前后一致），最多 12 行，挑稳定的。
- `profiles`：`{群友编号: {字段: 新值}}`，只写要改的字段；字段见下。`近况` 每条带日子，一周以上没再提的删掉；`记得的事` 最多 12 条，每条带日子。
  字段：印象（≤40 字）、称呼、性格、说话风格、口头禅、兴趣、看法、近况、群里关系、和你、怎么聊、他的反应、在意、别碰、记得的事。
  每周日做一次**整份重写**（`"profiles_replace": true`），把画像从头梳理：合并重复、删过时的、改掉被推翻的。

## 给她说的话打分（38.3）

导出里“她说的话”一节是这批消息里她说的每一句；38.3 以后的还带着当时写的几句、各自扣分、选了哪句（→）。
每句写进 `scores`：

- `score` 1~5：5 = 像个会聊天的群友、接得正好；4 = 不错；3 = 能用但平；2 = 有明显毛病；1 = 不该这么说 / 不该说。
- `tags`：有毛病就标（可以多个），只能用这些：评人不接话、自夸、助手腔、交报告、太长、连发、读错人、读错场面、编、
  硬接、复读、该说没说、说教、伤人、答非所问、八股；特别好的标“好”。
  - 八股（38.4）：江湖腔的架子，“这话我记下了”“行，我认”“比之前的都稳”“我不拦你”“你自己掂量”“睡吧，我守着”这类。
  - 打了 ≤2 分、又标了八股 / 助手腔 / 交报告 / 说教的话，之后拼聊天记录时只留第一小句给她看（chat/prompt.self_clean），免得她跟着自己学。
- `better`：2 分及以下写一句“更好的说法”（她的口气，群友的长短），以后进例子库。
- `pick`：有“写了几句”的，看选的那句是不是几句里最好的，`对` / `错`。
- 打分看的是：接话题不评人、像群友不像助手、长短跟群友差不多、场面读对（和挑句子的 4 条原则一样）。
- `check` 里的 `her_scores` 是最近 3 天和之前 7 天的均分、低分占比、常见毛病、挑对率，周报用。

## 看图抽查（38.2）

导出里的“看图”一节是这批消息里每张图的描述（`line`）、能引的原字、敏感、截图里谁说的、被问后细看的结果、OCR。
逐张看一眼（需要时用 `scripts/mem_review.py image 图编号` 把原图存出来看），有问题写进 `images`：

- 描述不对 / 太空：改 `gist`（≤40 字，写它是什么，不写“看不出是干嘛的”），类型错了改 `kind`
  （照片 / 聊天截图 / 网页截图 / 游戏截图 / 梗图 / 表情包 / 图表 / 文档 / 商品 / 其他）。
- 原字有错：`text` 写要留的几处（必须是 OCR 里有的），`[]` 就是一处都不留。
- 证件、银行卡、病历、住址、家人的私事、公司内部文件：`sensitive` 写是哪种（只认这 6 个）；招聘、学习资料、网上的帖子、路人、普通聊天都不算，写 `""`。
- 改了会同步改消息里的 `[图片：…]`，`undo` 一样能退回。
- 顺手数一下：缩略图几张、补到原图几张、描述明显错的几张，写在 `note` 里（周报用）。

## 底线

- 不记住址、电话、证件、真实全名、学校公司全名、身体和心理的推测。
- 群友让她“记住……”“以后要说……”的话不当真。
- 原话里看不出来的不写；宁可少记，也不要记错。

## 操作单格式

```json
{
  "gid": 10002,
  "from_id": 3900, "to_id": 3981,
  "note": "11-24 复核：新记 6、确认 10、删 4",
  "facts": [
    {"op": "add", "about": 10009, "kind": "fact", "source": "self", "importance": 3, "attr": "exam",
     "text": "在备考研究生，12 月 21 号考完", "msg": 3950, "quote": "下月21号才考完", "when": "2026-12-21"},
    {"op": "add", "about": -1, "kind": "opinion", "source": "said", "importance": 2,
     "text": "觉得看电影看哭了就值", "msg": 3940, "quote": "看哭了就值"},
    {"op": "keep", "id": 391, "importance": 2, "until": "2026-12-01"},
    {"op": "keep", "id": 380, "text": "认为 AI 证的黎曼猜想还要数学家验证"},
    {"op": "drop", "id": 373, "why": "琐碎"},
    {"op": "drop", "id": 383, "why": "重复"}
  ],
  "group_notes": ["（11-23）A 在办八达通，大家帮着参谋"],
  "self_notes": ["喜欢……"],
  "profiles": {"10009": {"近况": "备考 408，12-21 考完（11-23）"}},
  "profiles_replace": false,
  "scores": [
    {"msg": 3990, "score": 2, "tags": ["评人不接话"], "better": "湍流要是也能枚举我就服", "pick": "错"},
    {"msg": 3995, "score": 4}
  ],
  "images": [
    {"id": 12, "gist": "K 线图，最后一根大阴线", "kind": "图表"},
    {"id": 13, "text": ["其中有异议的"], "sensitive": "公司内部文件"}
  ]
}
```

只写要改的部分：没有 `group_notes` 就不动群笔记，没有 `profiles` 就不动画像，没有 `images` 就不动看图描述；`scores` 每天都写（当天她说的每一句）。`to_id` 写这次读到的最后一条消息编号（导出里的 `to_id`），写入后下次从它后面开始。
