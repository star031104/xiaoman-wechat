# 设计风格

> 这份文档只定**气质和方向**，不定死具体数值。颜色、圆角、时长写在各页面的样式变量里，以代码为准。
> 参考了 [Wakuwaku](https://github.com/zhoupengjie/Wakuwaku) 的设计文档：个性只放在角色身上，其余界面保持克制。

## 一句话

**像一个安静的家：东西摆得整齐、看得清楚；只有她本人是鲜活的。**

## 风格关键词

- **她是主角**：整个界面里，只有她（头像、她说的话）可以可爱、有颜色、会动。
- **安静**：平时不出声，有事轻轻提醒（小点、黄点），不抢你正在做的事。
- **清楚**：一眼看得出现在怎么样（她在干嘛、连没连上、有没有新消息）。
- **诚实**：做不到的写清楚做不到，出错了说清楚为什么、该怎么办。

不要的：满屏渐变和霓虹、一直在转的装饰动画、厚重投影、自己发明的奇怪控件、为了可爱让每个按钮都“卖萌”。

## 设计语言

### 1. 颜色：中性为主，颜色只表达意义
- 底色和文字用中性灰阶，深浅两套，跟随系统的深浅色。
- 强调色：私聊小屋是紫，群聊小屋是绿，托盘图标一粉一绿。按钮、开关、选中状态用它。
- **有意义的颜色**只出现在对应的地方：
  - 心情 / 情绪：只在她的头像、心情曲线上。
  - 连接状态四色：绿＝好好的，蓝＝装好了在等第一次，黄＝要你看一下，灰＝没开。全项目只用这四种，不加第五种。
  - 出错是红，只用在“确实坏了”的地方。
- 彩色只在两处：她本人，和有意义的状态色。别处保持素净。

### 2. 形状
- 卡片用大圆角矩形，同一类东西同一档圆角；气泡、标签、胶囊按钮两头全圆。
- 边框用一根细线，不用粗边框；阴影很淡，深色模式里不用阴影。

### 3. 字体
- 系统字体：Windows 上是 Segoe UI + 微软雅黑 UI，苹果上是 PingFang。
- 字重只用常规和中粗两档；大数字用细一点、大一点。数字用等宽数字（tabular-nums）。

### 4. 图标
- 细线条图标（1.8px 描边、圆头），和文字一个颜色。不用实心大色块图标、不用 emoji 当图标（README 的功能表除外）。

### 5. 动效：快、轻、播完就停
- 动画只用来表达变化：展开、收起、有新东西。
- 只有她本人能活泼：她的头像、心情。
- 系统关了动画（prefers-reduced-motion）时，不转、不跳，改成直接出现。

### 6. 她的表达
- **她说的话**：保持人设的口吻（这是唯一允许“有性格”的文字）。
- **在群里像真人**：分几条发、有“正在输入”、偶尔打错字再补一句“*正确的字”、发表情包；不用 markdown、不用括号写动作。
- **个性签名**：跟着她今天的安排和心情变，是她“自己的事”，不是系统通知。

### 7. 界面文字的语气
- 像一个靠谱的朋友：口语、简短、直接。
- 按钮用动词开头：“测连通、列模型”“重启生效”“换回上一个版本”。
- 不客套：不用“请”“成功”“感叹号”。出错时说清楚怎么了、可以怎么办（“NapCat 没连上：程序会自己再拉起它；一直不行就看日志”）。
- 说“她”（男性角色自动换成“他”），说“你”。

### 8. 隐私的样子
- 小屋只在本机能打开，不对公网开放；她放在服务器上时，用 SSH 隧道接到你自己的电脑上看。
- 改大模型 Key、更新这类操作只在小屋里做，不在聊天里回显密钥。
