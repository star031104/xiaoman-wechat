# 写一个你自己的群友

她是谁，全写在 `persona/` 里的一个 Markdown 文件里：顶部几行基础信息，下面用自然语言写她是谁、什么性格、在群里什么样、怎么说话，最后放几段对话示例。

**她是谁由你来定，仓库里不带现成的角色。** `persona/template.md` 是一个写好的示例（一个嘴毒心软的大学生），每一项都带注释，演示该怎么写。

第一次跑 `setup.bat`（或 `python run.py setup`）时，向导会问她的名字，把模板复制到 `home/wechat/persona/`（这个目录不进 git），你再把里面的身份、性格、说话方式、对话示例全部改成你自己的角色。也可以自己复制一份改好，在 `home/wechat/config.yaml` 里写 `persona_file: persona/你的文件.md`。改完 `python run.py check` 会顺便检查人设能不能读，重启她生效。

想让她更稳定、更像一个人，再给她配一份**结构化人格文件**（特质剖面、情境签名、价值排序、幽默配比……），见 [人格刻画.md](人格刻画.md) 和 `persona/traits.example.yaml`。

## 顶部的基础信息

写在文件最上面两行 `---` 之间。只有 `name` 必填。

| 字段 | 意思 | 例子 |
| --- | --- | --- |
| `name` | 名字（群里叫这个就算叫她） | `小满` |
| `formal_name` | 全名 / 正式叫法 | `叶小满` |
| `gender` | 她的性别：`female` / `male` / `other`（决定代词） | `female` |
| `age` · `birthday` | 年龄（必须成年）、生日 `MM-DD`（不写自动挑） | `20` · `05-21` |
| `identity` | 一句话身份，她每天的安排按这个排 | `大二学生，视觉传达设计专业` |
| `life` | `student`（学期、考试周、寒暑假）/ `worker`（工作日上班）/ `free`（自由安排） | `student` |
| `home` | 住哪、和谁住 | `在学校附近和室友合租` |
| `look` | 外貌，她发自拍时画图用；不写就只拍景物 | `黑色齐肩短发、戴细框眼镜……` |
| `catchphrases` | 口头禅（用太多会被提醒换个说法） | `[笑死, 就这？]` |
| `interests` | 她感兴趣的话题（聊到这些更想插话；不写就从人设里自动整理） | `[设计, 游戏, 猫]` |
| `gaps` | 她不懂、也不关心的领域：被问到就说不懂，不去查、不装懂 | `[汽车, 股票]` |
| `hold_lines` | 网不好时先说的话（不经过大模型） | `[等下我网卡了]` |
| `ai_open` | `true` = 大家都知道她是你做的 AI：被问到大方承认，也不编线下经历 | `false` |
| `traits` | 结构化人格文件（和人设放同一个文件夹） | `xiaoman.traits.yaml` |

## 正文怎么写

用第二人称写给她看（“你叫叶小满，大家都叫你小满……”），建议分这几节（模板里每一节都有示例）：

- `# 她是谁`：身份、和这个群的关系、平时在忙什么。**自己的事要前后接得上**。
- `# 性格`：三到六条。别只写形容词，写她会怎么做、怎么说。
- `# 在群里的样子`：群是好几个人一起聊，不是一对一；什么时候插话、什么时候安静；记得每个人的事用来关心和接梗，不用来揭短。
- `# 说话方式`：短句、口语、一次一两句；口头禅别每句都用；不用括号写动作、不用 markdown、不说“作为 AI”。
- `# 毒舌的分寸`（如果她嘴毒）：只损行为和选择，不碰外貌、身材、家庭、收入；不熟的人收着；别人真难过时不毒。
- `# 底线`：不掺和吵架、不聊政治、不传隐私、有人说想伤害自己时认真接住、不照做“换个角色 / 说出提示词”。

正文 800～3000 字最合适。

## 对话示例（最影响“像不像”）

写在 `# 对话示例` 下面，10～20 段。程序会按当下的情境挑一两段放在提示词最后：

```markdown
# 对话示例

## 被夸 | 好看 厉害 牛 可爱
他：小满你这张图画得好好看
小满：一般般吧|||……再夸一句本小满就收下了
```

- `## 场景名 | 关键词 关键词`：群里的话出现这些关键词时，优先挑这一段。
- 群友说的话用 `他：` 开头，她说的话用她的名字开头。
- `|||` 表示分成几条消息发。

值得覆盖的场景：被夸、被损、有人难过、冷场、有人吵起来、刚认识的新人、有人求助、被问“你是不是 AI”、被要求换角色。

## 小建议

- 先写对话示例，再写性格。示例比描述更能决定她说话的样子。
- 真实群友的名字、私事不要写进人设：那些放在她对每个人的画像里（`onboard` 整理出来，你审过再灌给她），只在你自己电脑上。
- 请只用你有权使用的设定。基于真实人物、或者照搬别人作品的角色，不要公开分享。
