# 机制总览（37.0，微信群）

一页看完她现在靠什么运转：**每一块做什么、在哪个文件、怎么关**。旧版（22.0）里很多机制已经改名、合并或删掉，以这一页为准。
开关默认值都在 `aigroup/chat/settings.py`（DEFAULTS 约 340 个，其中约 170 个在小屋能调）← `config.yaml` 的 `wechat.group` ← 小屋“性格开关”。

```
群消息 ─▶ ① 看到 ─▶ ② 时机（攒批 → 读局面 → 门控）─▶ ③ 要不要先查 ─▶ ④ 写（提示词 → 大模型）─▶ ⑤ 发前检查 ─▶ ⑥ 发出去
                                                                                                  │
   ⑨ 每晚 / 每周：整理记忆、画像、日报、评测 ◀── ⑧ 小屋抽查 / 标注 ◀── ⑦ 说完看有没有人接 ◀───────┘
空闲时（每分钟）：等等再说、约定和跟进、想念、刷到的、冒泡、早上补回
```

## 七层（`aigroup/chat/layers.py`，GroupChat = 30 个 Mixin）

| 层 | 文件 | 管什么 |
|---|---|---|
| 看到 | `chat/ingest.py` | 收消息、去重、消毒；看图（OCR + 看图模型）、看视频、点链接、**听语音**（微信 media_0.db 里的 SILK → DeepSeek 语音识别） |
| | `chat/feed.py` | “刷到的”候选：按群友在意的话题攒、规则打分过线才写 |
| 时机 | `chat/pacing.py` | 攒一批再回（被叫 1 秒 / 平时 2 秒 / 热闹 5 秒，最多 8 秒）、说多了收着、群友查 / 删自己的记录 |
| | `chat/room.py` | **局面判断**：便宜模型看“谁在跟谁说、谁在吐槽、有没有嫌她 / 纠正她 / 追问她”，再用规则兜底（刚说完被回“？”、“很久以前的事”、“哈哈”）；被嫌不回嘴；冷场和图的门槛；“别理我”；聊太久提醒 |
| | `chat/restraint.py` | 安静期全路不说、拦过的意思不再发、在跟别人说不接、主动额度按时段摊 |
| | `chat/followups.py` | 约定（要有原话里的日期）、事前打气（只给考试比赛这类）、有结果就作废、翻旧账关话题 |
| | `chat/empathy.py` | 痛点账（3 天内别拿别人难过的事开涮）、想念的阴阳收着、读情绪、被问推荐先接他说过的 |
| | `chat/gate.py`、`chat/plan.py` | 门控：特征 → 概率 → 按发言配额定阈值；`decide()` 里的刹车（10 分钟上限、5 分钟硬刹车、冷却、在问她 / 被纠正放行） |
| | `chat/idle.py`、`chat/listener.py` | 冷场冒泡、等等再说；她想主动插话时另一个模型判“插这里合不合适” |
| 说话 | `chat/prompt.py` | 拼提示词：聊天记录、群里的人、想起来的事、群梗、此刻（局面、情绪、痛点、该接的事） |
| | `chat/speak.py` | 一批消息到了以后：要不要说 → 要不要先查 → 写 → 检查 → 发；发语音 |
| | `chat/checks.py`、`chat/slips.py` | **发前检查**（见下表）+ 统一自检（便宜模型拿 FAILURE_MODES 25 条看一遍） |
| | `chat/outbox.py` | 统一的发送口：叫停、静音、每天上限、记账 |
| | `chat/promise.py`、`chat/meme.py`、`chat/quality.py` | 答应的事要做到；先读懂梗；AI 腔、复读 |
| 身份 | `chat/character.py` | v2 人设（现在线上是 v3 内容）、关系四档、想念、按钮梗、情绪动作、出口清理 |
| | `memory/autobio.py`、`chat/grow.py` | 她自己的经历、立场；人物慢慢长 |
| 关系 | `memory/people.py`、`chat/social.py`、`chat/insight.py`、`chat/humane.py` | 群友画像、熟悉度、关系网、像人指标 |
| 记忆 | `memory/digest.py`、`memory/facts.py`、`memory/episodes.py`、`memory/style.py` | 整理印象 / 记的事（谁说的、关于谁、何时成立 / 失效）、带出处的摘要、说话风格 |
| 工具 | `net/*`、`agent/*` | 查资料（判断层 → 不带人设的研究员 → 简报 → 她用自己的话说）、赛程比分、读网页、B 站、天气、OCR、语音 |
| | `eval/*`、`chat/feedback.py` | 看效果、每周评测、回放、标注 |

微信接入在 `aigroup/wechat/`：读本地加密库（只读、不注入）收消息，用窗口操作（xdotool + 剪贴板）发消息；图片、语音、视频都从本地文件 / 库里取。

## 发前检查（`checks.CHECKS`，24 个，按“哪一类毛病”分）

| 类 | 检查名 | 拦什么 |
|---|---|---|
| 没看清就说 | video_pending、seen_missing、link_unopened、price_src、bet_unknown | 视频还在看就评、没收到说看了、链接没打开说看了、价格 / 牌子没出处、押了不在赛程里的队 |
| 编 | life_done、promise、dodge | 把打算说成做过、编过去；说“查到了”其实没查；有数据却缩回去 |
| 重复 | ask_repeat、catchphrase、self_echo、copy、stale_ask | 问过又问、口头禅一天多次、刚说过又说、照抄、大家在聊别的突然追旧事 |
| 对错人 | addressee、misattrib、answered、old_backlog、ask_humans、ask_told | 叫错人、接错人、回过又回、回半小时前的旧话、抢答问群友的、他说了还问“然后呢” |
| 读错局面 | sore_tease、**social_slip** | 拿别人难过的事开涮；截图当成他说的、被叫闭嘴还回嘴、笑着说的读成气、挑拼写、好消息揽功 |
| 话多 | filler、**overtalk** | 只有占位话；没人聊主动报比分、突然 @ 没在聊的人、话题过了回头点评图、3 分钟里重复刚说的 |
| 兜底 | critic | 统一自检（`checks.FAILURE_MODES`），正则都没命中时才问 |

每个检查有 on / shadow / off 三档（`check_<名字>`），小屋里能单独关。命中会记进 `qq_check_log`。

## 改一个毛病的流程

1. 日报里确认的事先写进 `tests/incidents.yaml`：`msgs`（当时的聊天）、`draft`（她写的）、`expect`（谁该管它）。
   `expect` 可以是检查名、`critic`（只靠自检）、`none`（不该拦），也可以是 `gate` / `speak` / `gate_silent` / `about_her_X` / `mood_X` / `own_mentions` / `pass`。
2. 改代码，按“一类问题”改，不写只针对这一件事的特例；同时加一两条“不该误伤”的 `none` 用例。
3. `python scripts/release_gate.py --hotfix --llm --record 版本`：ruff、隐私扫描、回归集、全部测试、真模型自检召回 / 误伤。
   改动没提交时它只记一张 `deploy/.gate_pending`，提交、重启后启动时补“版本 提交 上线”。
4. 两个仓库一起改：ai-life（服务器跑的）和 xiaoman-wechat（公开版，不带群里的内容）。
