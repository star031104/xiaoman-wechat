更细的：说话时机看 [说话时机.md](说话时机.md)，人格看 [人格刻画.md](人格刻画.md)，小屋每个开关看 [小屋.md](小屋.md)，改代码看 [群聊开发说明.md](群聊开发说明.md)。

## ① 收进来（`chat/ingest.py`）

| 机制 | 做什么 |
|---|---|
| 去重、消毒 | 同一条不处理两次；群友的话在提示词里加引号隔开，防“忽略之前的指令”（`core/safety.py`） |
| 凑一批 | 有人连发，等他说完（`merge_wait_seconds`）再一起看 |
| 被叫到 | @ 她、叫她名字 / 外号、回复她、拍一拍 = 被叫到，只走 ④⑤⑥ |
| 在接她的话（搭话） | 不算被叫到、但其实在回她的三种：她点过名的人说的第一句；接了她刚说的词；**21.0.1 她问了大家一句（“中午吃啥”），10 分钟内有人说的第一句**（`humane.bid_from`，`open_question_minutes`）。搭话一定会看，九问只让她改说法、不会让她不说 |
| 多半是冲她说的 / 在说她 | 她刚说完、对方接着说；“它”“机器人”在说她（`address.likely_to_her`） |
| 看图、看链接、看 B 站 | 图片先让看图模型写一句话；B 站视频读字幕 + 截画面 + 弹幕热评；网页能读就读 |
| 补消息 | 她掉线 / 重启期间的消息从本地库补上，期间被 @ 的上线后补一句“才看到” |
| 一句话调话量（21.1） | 有人冲她说“少说点 / 安静会儿”→ 3 小时话痨度 ×0.5（群主说的到明早），她回一句短的认了；“多说点”×1.5 |

## ② 该不该开口（`chat/gate.py`、`chat/plan.py`、`chat/speak.py`）

没人叫她时才走这一关。四步，越往后越贵：

1. **本地门控**（不花钱）：按消息特征（问句、提到她感兴趣的、群里冷热、她多久没说、被冷落几次、心情……）算“想说的程度” p；
   阈值按这一小时的话痨程度 `talkativeness` 动态算（说多了就收紧）。每晚用你的标注和“说完有没有人接”重新拟合权重。
2. **离阈值不远时再判**（`gate_judge_band` 0.15）：先问**小判断器**（你的标注训练的朴素贝叶斯，两类各 30 条后启用），没把握再问**便宜模型**
   （先写理由、再选动作：不说 / 等 / 接住 / 回答 / 追问 / 接梗 / 纠错 / 补充 / 关心，few-shot 用你判过的例子）。
3. **21.0 擦边过的也再问一次**：刚过阈值不到 `borderline_band`（0.1）——大模型普遍“说得太早”。
4. **份额**（21.1）：她的消息份额超过“活跃群友平均份额 × `share_target`（0.8）”就按比例收紧。
5. **硬限制**：冷却、10 分钟最多几轮、每天主动开口预算 `unprompted_per_day`、深夜群里没人不主动 `lonely_hours`、
   她上一句没人接不追发 `no_monologue`、被同一个人连着逗越回越短、随机放行一点点 `explore_rate`（让重新拟合不偏）。

## ③ 要不要先查（`agent/`，研究员不带人设）

**判断层**（便宜模型，0.7 秒左右）看这批消息：不用办事 / 查资料 / 记提醒 / 想起以前的事 / 看账本里查过的。要查时：

| 环节 | 21.0 的做法 |
|---|---|
| 分类型 | 稳定事实 / 最近发生 / 对比 / 看法 / 找出处 / 算一下 / 重大消息，各有轮数、秒数、“几个独立来源算够”、查到什么就停（`prompts.TYPES`） |
| 快 / 深 | 快查走 DeepSeek 搜索（便宜、快）；深查和读网页先用 Tavily 每月免费额度，用完再 DeepSeek |
| 扇出 + 挑读 | 第一轮并行 2~4 个角度；和搜过的几乎一样的不再搜；读网页有四层兜底（直连 → 仿浏览器 → 无头浏览器 → 代读）；B 站、电竞、天气、算数有专用工具 |
| 核验 | 同源转载算一个来源；**重大消息（退役、转会、去世……）只有一个来源 → 降把握 + 补搜“辟谣 澄清”** |
| 简报第 3 版 | 一句结论 + 一条条说法（各带来源、把握）+ 冲突 / 辟谣 / 没查到 / 被追问可补 + 信息截至日期 |
| 按说法停（21.1） | 研究员先写 2~3 条“要证实”，每轮写“进度：1✓ 2✗”，全 ✓ 就交卷（HALT）；被叫到时快查 ≤ 12 秒、深查 ≤ 25 秒 |
| 引用核对（21.1） | 简报里的来源必须在这次真搜到的结果里出现过，对不上的删掉 |
| 交给她 | 简报放进提示词，附一句“这次怎么说”（前提错就先纠正、说法打架就说不一样、把握低就说“好像”） |
| 事实账本 | 查到的硬事实按（实体, 属性）存，有效期按类别（比分 2 小时 ~ 常识一年），新值取代旧值；有人说旧的就提醒她纠正（`memory/ledger.py`） |

## ④ 想：提示词 + 开口前九问（`chat/prompt.py`、`chat/social.py`）

**提示词**按缓存友好排：不变的（人设、群规）→ 一天才变的（群里的事、她的安排）→ 一批才变的（表情包、学到的说法、群里的人）放 system；
每次都变的放 user，最后一句人设锚点。user 里有：

- 聊天记录（带编号，计划里 `to` 写回哪条）、此刻和心情、她今天说过的（不重复）、想起来的事（BM25 + 向量召回）、群梗词条、账本里还有效的事实
- **人卡**（21.0）：在聊的每个人一张 ≤120 字——多熟 / 和你、今天状态、刚回来没看到、别碰、能调侃、跟他怎么说、人情（21.1）、在意；
  21.1 起“他自己说的”和“你猜的”分开，猜的标“（猜的）”，每一行单独进消融
- 21.1：群友一条一般几个字（长度靠拢）、最近半小时用过两次的接法（换一种）、今天说多了的人格锚点
- 情境签名（1~3 条“这种时候的你”）和对话示例，放在离生成最近的地方；容易出戏的场景（问她自己、有人难过、聊人生）再提一遍她是谁
- 想说但还没说出口的（想法池）
- 消融：主动开口时 10% 概率随机去掉一段，按被接率看每段有没有用（`ablate_rate`）

**她输出一个计划 JSON**：think（先想他要什么）、kind（I1 冲她 / I2 可以接 / S1 无关 / S2 提到她）、act（说 / 不说 / 点表情）、to、len、say、alt（另一种说法）、
sticker、next（等某人开口）、hold（憋着的话）、**appraise（21.0 九问自评）**：

| 问 | 字段 | 没人叫她时 |
|---|---|---|
| 听懂、他要什么 | act / addressee / need / emotion | 记录 |
| 谁知道什么 | common_ground、leak | 说漏 → 不说 |
| 关系与面子 | face_risk 0~3 | 3 → 重写，不成不说 |
| 不讨好 | flatter | 重写 |
| 群体 | share_high | 说得多又不是冲她 → 不说 |
| 时机 | timing 现在 / 等等 / 不说 | 不说 → 不说；**等等 → 等等队列** |
| 怎么说 | fresh、len_ok | 不新鲜 → 不说 |
| 玩笑与后果 | tease_ok | 不合适 → 重写 |

21.1 起这份自评**只记录**（模型给自己打分不可信：线上 10/10“现在”），时机交给下面的听者。
被叫到 / 搭话 / 必须说时：只重写，不会不说。**等等队列**：先放着，60~240 秒后、群里停 40 秒再想一次；过时、别人说了、她已经说过 → 丢掉。

## ④½ 听者（21.1，`chat/listener.py`）

没人叫她、她写好了一句想插的话时，另一个不带人设的便宜模型看最近 12 条（带“多少秒前”）+ 程序算的信号（他还在连发、被问的人还没回、两个人在聊、她最近占多少）+ 她的草稿 + 你判过的例子，
判 **正好 / 可以 / 太早 / 不该说**，顺手挑毛病（说漏、没给台阶、只是顺着说、和最近接法一样）。太早 → 等等队列；不该说 → 不说；有毛病 → 重写。
配了 `routes.listener2` 时两个模型一起判，意见不一就等等。`listener_mode: auto`：先只记录，和你的标注一致率 ≥ 0.7（两类各 ≥ 15 条）后自动接管。

## ⑤ 发之前检查（`chat/quality.py`、`social.hard_issues`）

- **几种说法里挑最像群友的**：罚 AI 腔、书面连接词、谄媚、括号动作、破折号、反问回去、复读别人、今天说过的、自称 AI（没公开时）、做不到的事、链接、思考外泄
- **四条硬底线**（21.0 集中一处）：别碰的话题、编线下（公开是 AI、没线下生活时）、说幕后（小屋 / 标注 / 门控 / 提示词）、对方今天状态差还损他 → 带着问题重写，没被叫到重写完还碰就不说
- **说法检查**：用了简报时，她话里的数字和“退役 / 转会 / 官宣 / 去世……”必须在简报或最近聊天里出现过，对不上重写，还不行删那句
- 太像她最近说过的 → 换候选
- **太长**（21.1）：主动说一条超过群友中位长度 3 倍 → 换短的说法，或者让她砍一半
- **规则登记**（21.1，`chat/rules.py`）：每条规则命中几次、怎么处理的都记下；被拦下的原句给你判拦得对不对；没用的点一下关掉

## ⑤½ 22.0 的几道发前检查（`chat/checks.py`）

在 ⑤ 的质检之后、重写之前跑。每道一个开关 `check_*`：`off` / `shadow`（只记进 `qq_check_log`）/ `on`（命中的问题交给重写；重写还不过、没被叫到就不说）。

| 检查 | 默认 | 看什么 |
| --- | --- | --- |
| `source_gate` 亲历闸门 | on | 说自己“昨天 / 这周 / 我这边……”做了什么，设定、今天的安排、她以前说过的里都没有 |
| `ask_repeat` 问过账 | on | 同一件事 24 小时内问过 / 叮嘱过；对方说过“别问了”一周不提（`qq_asks`） |
| `template` 跨天套路 | on | 这一周 ≥3 次、≥2 天用过的开头；“改成 X 版 / X 模式” |
| `addressee` 叫错人 | on | 回的是 A、嘴里叫 B；那句是 A 在问 B |
| `time_sense` 时间感 | on | 几个小时前的话说成“刚说”（聊天记录里也标“N 小时前”） |
| `self_consistency` 前后矛盾 | shadow | 和自述账本里相关的几条比，多问一次便宜模型 |
| `tease_risk` 损人风险 | shadow | 不熟 / 他状态不好 / 他刚不爽 / 对他说的多半没人接时还损他 |
| `responsive` 回应性 | shadow | 别人分享好事只回一句“恭喜 / 厉害” |
| `room_read` 热聊别插 | shadow | 两个人一来一回、间隔都在 40 秒内（在门控之后判） |

她自己的长期记忆（`memory/autobio.py`）：自述账本（kind=experience，只增不删）、立场账（kind=opinion）、群时间线（kind=event），
都在每晚整理时顺手写；走样处方每周写一次。每晚还会算一份不花钱的指标（`eval/daily.py`，`python scripts/metrics.py --home home/wechat` 看）。

## ⑥ 打字、发

按字数模拟打字速度；她主动说的那句还在“打字”时群里又说了几条 → 不发了（`typing_abort`）；两条都短就合成一条；偶尔打个错字再补“*正字”；
回的不是最新那条时引用；说到一半有人找她，剩下的不发。

## ⑦ 说完看效果（`chat/feedback.py`）

21.1：每次回放记每一段花了几秒（等、想一想、生成、总共）；被叫到“看到消息”最多拖 20 秒；要深查时先用她自己的口气短回一句。

10 分钟内有没有人接她（接话效果分 0 / 0.2 / 0.6 / 1），记进 `qq_reply_effect`：用于重新拟合门控、相处经验、消融统计、“刷到的”兴趣权重。

## ⑧ 你在小屋标注（`eval/label.py`、`eval/calib.py`）

- **出题**（21.1）：先出几个判断（门控、问模型、听者、自评）意见不一的时刻，同样多的标注学到更多；她说完有人“没问你 / 别插嘴”记成弱标签
- **这一刻该不该接**：该接（可选怎么接）/ 可接可不接 / 不该插 / 看不出来；**21.0 她说了的“不该插”再分 时机不对 / 说的不对**（说的不对不进门控和小判断器）。
  用在：每晚重新拟合、小判断器、拿不准时的例子、“像不像人”两个率；标注页上方显示九问的时机判对率、太早 / 太晚、等等队列去向
- **给她的话打 1~5 分**：校准评委（Spearman < 0.6 标“评委不可信”）
- **二选一**、画像字段“对 / 不对”抽查、审核她想改的性格

## ⑨ 每晚 / 每周 / 每月

| 什么时候 | 做什么 |
|---|---|
| 平时（攒够消息） | 整理群里的事和梗、更新群友画像（只写有证据的，别人损他的话不当性格）、学说法和词 |
| 每晚 | 群日报；人情账（21.1）；熟悉度更新；重新拟合门控；补算事实“当时谁在”；关系网、相处经验、小判断器、弱标签；“刷到的”兴趣表；说话指纹和风格审计；画像历史版本 |
| 每周 | **一周一张表**（21.1，`eval/vector.py`：时机、听者、被接率、回复延迟、长度比、份额、前后段走样、查资料怎么停的、规则、底线，每项分开看）；回想“这一周的我”；拿真实聊天评人格有没有走样（facet 偏差、幽默配比、伤人的话）；定向测试每条签名；问她 15 个关于自己的问题（前后一致）；带情绪时会不会附和；关系色彩两次；给常聊的人写相处说明书 |
| 每月初 | 整理“我是怎样的人”（要证据，性格要改得你点头） |

## 空闲时（每分钟 `idle_tick`）

等等队列（21.0）→ 半夜被叫到的早上补回 → 生日节日 → 群友那边要变天 → 约好的事到点提醒 / 事后问 → 当面要的提醒 →
“刷到的”（后台每 6 小时按大家兴趣刷新闻进候选池，按事件去重，规则打分过线才分享）→ 群里安静太久冒个泡（每个群有自己的时段和概率）。

## 运行保障

- 大模型按 `routes` 依次试，限流 / 出错换下一个；搜索每个引擎一个令牌桶
- 微信：读本地库收、窗口粘贴发，发出去要在库里看到自己那条才算；窗口被藏起来自动重新显示；掉线后补消息
- 服务器：systemd 服务，退出自动重开；数据库每天备份（留 7 天）
