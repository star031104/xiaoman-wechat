# 小屋使用说明

“小屋”是她自带的网页：看她现在怎么样、她记得什么、她心里每个群友的样子，也能直接改。

本机地址 **http://127.0.0.1:8768**，或者双击任务栏右下角微信绿的 **W** 图标。

小屋只听本机：别人在局域网里打不开。放在服务器上时，用 SSH 隧道在自己电脑上看：
`ssh -N -L 8768:127.0.0.1:8768 ubuntu@服务器`（或 `scripts\open_home.bat`），再打开 http://127.0.0.1:8768 。

> **先别慌**：页面上的东西大部分是“给你看的”，不用动也能好好跑。第一次用只需要确认三件事——
> ① 概览最上面的连接是绿的；② “大模型”里至少有一个接口；③ 人设是你想要的那个。其余的等用着觉得哪里不对再来调。

颜色只有四种意思：**绿** 好好的　**蓝** 装好了、在等第一次　**黄** 要你看一下　**灰** 没开。

**17.0 起的样子（B 版「窗边日常」）**：样式都在 `aigroup/web/tokens.css`。
- 首页最上面是“她此刻”和她的立绘，颜色跟着真实时间走：早上暖白（5–16 点）、傍晚玫瑰（16–21 点）、深夜深紫（21–5 点，立绘上加一层暗色）。
  深浅色默认跟系统，右上角“…”菜单里可以手动切。
- **立绘和头像**放在她家的 `data/avatar/` 里（默认是 `home/wechat/data/avatar/`），
  文件名带 `portrait` 的是立绘、带 `avatar` 的是头像（没有头像就用立绘）。这些图不进 GitHub。
  配了 `routes.image_ref`（比如硅基流动的 Qwen/Qwen-Image-Edit-2509）时，同一批图也是她“画自己”的参考图，自拍长相一致。

**18.0 起（「小屋」版）**：整体换成暖纸色、奶油白卡片、深棕文字，深色是“夜里开着小台灯”的暖棕。
- **顶栏一行**：左边她的头像和名字，中间是页面，右上角“…”里是切深浅色、刷新、使用说明、打开 / 关上管理。
  手机上页面挪到底部的一排按钮。
- **首屏标题最多 16 个字**：她正在做的事太长时，在第一个逗号处断开，后半句放在下面一行小字。
- **空的卡片不占一整行**：一块里什么都没有时，两张空卡片并排、收紧，不留大片空白。
- **群聊小屋分两半**：首页、她的日子、她是“角色视图”；群聊、群友、学到的，以及管理里的性格开关、大模型、日志在“工作台”里，
  工作台左边有侧栏，字号和行距更紧凑。

## 小屋里有什么

上面一排是首页、她的日子、她和“工作台”；
工作台左边的侧栏是群聊、群友、学到的，打开管理（右上角“…”）后多出性格开关、大模型、日志。
她待好几个群的时候，大多数页面上方有一排按钮（群超过 5 个时是下拉框）切换看哪个群；选“全部”就是所有群放一起。

### 首页

- **她此刻**（首屏）：时段和在不在线、她现在在干嘛（照她自己当天的安排）、心情一句话、她最后说的一句话；“帮她判该不该说”直接跳到“学到的”。
- **今天的群**：标题旁边一排按钮切换看哪个群（只有一个群时不显示；图表跟着变，点“看群聊”也打开这个群）。
  下面只放**要你留意的**状态胶囊（掉线、发不出去、免打扰中）；一切正常时这一行是空的，平台账号、免打扰时段、冒泡时段、已经运行多久收在“更多数字”里。
- **最上面的平台标签**：连上时是蓝色（她的昵称和号），掉线时是红色（“微信没接上 / 微信没在运行”），这时标题也会变成“她掉线了”。鼠标停在红色标签上能看到原因和该怎么做；详细步骤见 [GROUP_WECHAT.md](GROUP_WECHAT.md) 常见问题里的“掉线了”。
- **四个大数字**：群里一共多少消息、她说了几句（都和昨天比）、多少次有人找她、她说完有没有人接（“接话率”，越高说明她插话插得是时候）。
  认识多少人、有画像的、调了多少次大模型在“更多数字”里。
- **消息图**：右上角“今天 / 两周”切换——今天每小时的消息（灰的是群友、紫的是她），或两周的消息量、她说的、大模型调用。旁边是她今天的安排。
- **几个群放一起看**：只有一个群时不显示。看她在哪个群更放得开、哪个群说完没人接；数字最大的加粗。
- **她最近说的 / 她待的群**：她最近说的几句；每个群一张卡片（好几个群时并排占一整行）。黄色的提示要看一下（比如微信群“没有单独窗口”：在微信里双击这个群，让它单独开一个窗口，可以最小化，别关）。点“看聊天”去这个群的聊天记录。

### 她的日子

她自己的生活和她记着的事。大多数可以直接改，改了马上生效。

- **这一周的她 / 她是怎样的人**：她每周一回想一次这一周，每月初沉淀成“我是怎样的人”。觉得哪里不像她，直接改文字再保存。
- **她说过的喜好**：她在群里亲口说过的“喜欢 / 讨厌 / 支持哪个队”。记下来就不会改口；不对的删掉。
- **和大家多熟**：每个人和她的熟悉度。找她聊天会慢慢变熟，越熟越敢损。
- **她记着的约定**：“周四开黑”“下周二面试”这类，到点提醒大家，事后问结果。可以手动“记下”一条。
  19.0 起有人当面让她提醒的标“当面要的”（到点就发，免打扰也发）；19.2 起每条能“改时间”，没说出来会写“没说出来 N 次，过会儿再试”，
  “历史”里看得到说过的、错过的（程序停太久）、没说出来的、取消的。整理出来的约定错过了时候会顺延，晚太多改成过后问一句。
- **大家在哪**：群友说“在珠海出差”她会记下，那边要下大雨、降温会提醒一句。记错了就删。
- **日程**（18.0 把约定、大家在哪、生日和节日放进一张卡片的三栏）：生日在“填群友的生日”里填，那天上午她会在那个人常待的群里祝一句。
- **她分享过的**：她偶尔转进群的东西；“现在分享一次”“发张照片”可以手动触发（照片要配了画图接口）。
- **她最近知道的事**：她搜到的、读到的、被纠正过的知识。聊到关键词会想起来；错的删掉。

### 群聊

- 完整的聊天记录，能搜；上面切换群。
- **让她开口**：给个话题（可以不填），她按人设现在说一句。
- **替她说一句**：你打的字原样用她的号发出去（她会记得这是“她”说的）。
- 右边“让她开口 / 她记得这个群的事 / 这个群”三块可以点标题收起来。
- **闭麦**：勾上以后这个群她只看不说，照样记消息、认人。
- **她记得这个群的事**：群最近的事和梗，她每整理一次群聊会在这个基础上更新；可以直接改。

### 群友

- 每个人一张卡片：印象、称呼、熟悉度、常出现的时间。可以按“最近出现 / 最活跃 / 最熟 / 有画像”排。
- 点开一个人：她对他的完整画像（大家怎么叫他、性格、说话风格、兴趣、近况、别碰的话题、记得的事）。
  - **别名**：大家怎么叫他（真名、外号，顿号隔开）。群里一提到这些名字，她就知道说的是这个人。
  - **按群分开**：同一个人在两个群里，她在每个群里的了解分开记——在一个群知道的事不会拿到另一个群说。
  - **改画像**、**让她重新整理**、**忘掉**（只忘这个群，或者全部）。
  - **画像抽查**：每一项旁边点“对 / 不对”，标错的下次整理时重写；群友页上方会写你抽查过多少项、对了几成。
  - **她和他相处的经验**：每晚从她对他说的话有没有人接总结的几条（16.0），只读。
- **关系网和相处经验**（17.0 放到了群友页最上面）：谁和谁常聊（这两周的回复、@、紧接着说话数出来的）和每个人的相处经验，每晚整理一次。

### 她

- **这几天的安排**：她每天早上自己排的作息，群里聊起来前后一致。“重新排”可以让她重排今天的。
- **她感兴趣的**：聊到这些更容易插话。
- **她记得自己的事**：她在群里说过的关于自己的事（每个群分开），防止前后矛盾。
- **人设全文**：现在用的人设。要改人设，改 `home/<名字>/persona/` 里的文件。

### 学到的

她从群里学来的东西，都能删、能停用。

- **这一刻她该不该说**放在最上面（见下）。
- **她现在想不想开口**：外面只放三个数（想开口的门槛、1 小时里主动说了几次、精力），其余二十来项在“门控细节”里。最近 1 小时的“发言配额”。每一批消息她都会算一个“想说的概率”，过了阈值才会真的去想说什么。想让她话多一点，去性格开关调“话痨度”，不用动这里。
- **说话方式 / 群里的黑话**：“当……时，可以说……”和离开这个群就看不懂的词。出现两次以上自动用；学歪了点“不用”。
  每一条右边是一个三段开关“用 / 自动 / 不用”（群梗词条、表情包也一样）。
- **帮她挑一句**：她给出两种说法时你挑更像群友的那个。挑得越多，她越能分辨什么是“AI 腔”。
- **这一刻她该不该说**（13.0）：给你看某一刻之前的十来句和她当时做了什么，你判“该说 / 不该说”。优先挑她说了没人接的、拿不准问过一下的、
  离阈值很近的。上面的数字：她和你一致的比例、她说的里面该说的比例（精确）、该说的里面她说了的比例（召回）。
  你判的进每晚的重新拟合，权重最高——判个一两百条，她什么时候开口会明显更合你的意。
  **键盘**：<kbd>Y</kbd> 该说、<kbd>N</kbd> 不该说、<kbd>S</kbd> 看不出来（光标在输入框里时不算）。上方有这次判了几条，和小判断器（16.0）
  “该说 / 不该说”各要 30 条的进度（每晚整理时数，当天判的第二天算进去）。
- **群梗词条**：一个关键词 + 一句解释。聊到关键词时才告诉她这个梗的意思，提过以后一阵子不再提。
- **她从网上看来、记住的 / 她记的事**：链接里读到的、搜到的、群里发生过的事。每条事写着来源（他自己说的 / 听别人说的 / 猜的）和从哪天起、有效到哪天；过时的点“过时”。
- **群规矩**：整理群聊时总结的不成文规矩（“大家互称 X 总”“一句话拆好几条发”），她会照着来；可以改。
- **存的表情包**：群里被两个以上的人发过的才存，意思是从大家什么时候发它猜的。
- **群日报**：每天早上整理前一天：多少人说话、谁最活跃、几件好笑的事、她说完有没有人接。
- **像不像人（这一周）**（19.1）：该说没说、不该说却说（用你判的“该不该说”）、搭话接住率、当天说重复的次数、没人理还追发的次数。
- **盲测**（19.1）：点“出一组”，她这周说的混在群友说的里，勾出你觉得是她的，交卷看猜中几句。猜不出来 = 她说话像群友。
- **她查过什么**（19.2）：“先想一想再回”打开后，每次查了什么、快查还是深查、几轮、几秒、是不是到点交卷、把握、要点、来源，展开看每一步；
  上面一行是今天查了几次 / 上限、Tavily 这个月用了几次（免费额度用完会写出来），19.3 起还有“读网页”现在能用哪几层
  （直连 → 仿浏览器 → 无头浏览器 → Tavily 代读；没装的不显示）。每一步里能看到她用了哪个工具（搜索、读网页、B 站、电竞、天气、算数）。

### 管理 → 性格开关

拖一下马上生效，存在她的数据库里，重启也在；每一项旁边有“恢复”，最下面可以“全部恢复”。
18.0：上面有搜索框（搜名字或说明）、“只看已调”，和一排分组目录（数字是这一组调过几项），点一下跳到那一组。

- **全局 / 只调某个群**：上面选“所有群（全局）”调的是默认值；选某个群就只对那个群生效、盖在全局上面（开关后面会标“单独调过”）。
  灰掉的几项只能全局调（每天一次的整体整理这类）。
- **每周评测**：每周一挑她说过的 10 句找毛病打分（满分 100），人设改过会和上一版盲比。也可以点“现在评一次”。

**最常见的几种调法**

| 你觉得 | 调这个 |
| --- | --- |
| 她话太多 / 太少 | **话痨度**（先 ±0.05 试一天）；“10 分钟最多说几轮”是硬上限 |
| 她回得太快，不像真人 / 太慢 | **回复节奏倍数**（0.5 = 快一倍，2 = 慢一倍） |
| 她老是分好几条发 | **一次最多几条** 调成 1 |
| 她总叫人名字，这个群大家其实不叫 | 切到这个群，关掉 **叫人名字 / 称呼**（没设的话她会自己看群友的习惯） |
| 群里冷场时她老冒泡 | **冒泡概率** 调低，或者 **群冷多久会冒泡** 调大 |
| 有件事想专门交代她（“别提考研”“大家互称 X 总”） | 切到这个群，写 **关于这个群的交代** |
| 费用 | 关掉 **看群里的图片**、**多写几种说法挑一条** 调成 1；每天花费上限在 config.yaml 的 `llm.budget` |
| 她该接的时候老是不接 | 打开 **拿不准时问一下**（13.0 默认开）；去“学到的”判一些“这一刻她该不该说” |
| 她一天里主动说得太多 | **每天主动开口最多几次**（插话、冒泡、分享加起来，不算被叫到） |

**13.0 新加的开关**

| 拿不准时问一下 | 开 | 差一点就想插话时，让便宜模型判断“说 / 等 / 不”（只回一个字，每群每小时最多 20 次） |

**全部开关**（括号里写的 QQ 群的默认值可以忽略：这套大脑最早是给 QQ 群写的）

**说多少话**

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 话痨度 | 30% | 最近 1 小时里留给她的发言份额；她说多了会自动收紧，范围 0～1 |
| 10 分钟最多说几轮 | 6 | 被叫到时放宽到两倍，范围 1～30 |
| 两次插话最短间隔（秒） | 60 | 没被叫到时，范围 0～1800 |
| 一次最多几条 | 2 | 一轮回复最多拆成几条消息，范围 1～5 |
| 多写几种说法挑一条 | 2 | 1 = 只写一种；2~3 会多花一点输出，范围 1～3 |
| 随机试一次的比例 | 2% | 本该不说的时候偶尔说一次，让以后的自我调整不偏，范围 0～0.1 |

**节奏（像不像真人）**

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 回复节奏倍数 | 1.0 | 看到消息、打字的等待时间都乘它；0 = 秒回，范围 0～3 |
| 打字速度（字/秒） | 6 | 越大越快，范围 1～30 |
| 按群友的节奏回 | 开 | 从这个群群友自己的回复间隔里抽“看到消息”要多久 |
| 打错字的概率 | 3% | 偶尔打错一个字，有时补一句“*正确的字”，范围 0～0.2 |

### 管理 → 大模型

- **今天的调用**：每个接口今天用了多少次、成功率、平均多久、被限流几次。
- **每种活用哪个模型**：聊天、后台小活、整理印象、排安排、看图、画图……每种活按顺序试，前一个出错就换下一个（绿色的是主力）。
- **添加大模型接口**：填接口地址（任何 OpenAI 兼容的，一般以 `/v1` 结尾）和 Key → 自动列出这个接口的模型 → 选一个 → “试聊一句”看看速度 → 选“放到最前面（主力）”“放到最后（兜底）”还是“只用来聊天” → “加进去” → “重启生效”。
  加的接口写在 `home/<名字>/config.llm.yaml`，Key 写在 `.env`，不动你的 `config.yaml`。

### 管理 → 日志

实时日志，可以只看“她说的”或者“警告 / 出错”。她该说话没说、说了奇怪的话，先来这里看她当时怎么想的（每次开口前她会写一句“她想：……”）。
