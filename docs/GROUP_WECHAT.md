# 微信群里的她

这是她在微信群里怎么工作的详细说明：群聊大脑在 `aigroup/`，接微信 4.x 的部分在 `aigroup/wechat/`，用单独的微信小号。
她的家在 `home/wechat/`。怎么装、怎么启动看[根目录的 README](../README.md)；放在 Linux 服务器上见 [WECHAT_LINUX.md](WECHAT_LINUX.md)；配置项的完整说明在 `config.wechat.example.yaml`。

## 怎么接微信的

**不 hook、不注入、不改微信的任何文件**，所以微信更新了也照常能用（只要你也跟着更新就行）：

| | 做法 | 微信更新后 |
| --- | --- | --- |
| **收消息** | 读电脑上微信自己的本地数据库（只读）。库是加密的（SQLCipher 4），密钥用 `ReadProcessMemory` 从微信进程内存里**只读**找出来，每个候选都用库第 1 页的 HMAC 验过才用（零误报）。拿到后存在 `home/wechat/data/wechat/keys.json`——微信更新不会重新加密库，所以一直能用。之后每秒看一眼库变没变，变了只解密变了的页（主库 + `-wal` 增量），找出白名单群里的新消息 | 基本不用管。新建的消息分片库（`message_1.db`…）需要再拿一次密钥：找不到时 `python run.py wxkeys --deep` 用“把内存整个筛一遍”的办法，不挑版本 |
| **发消息** | 普通的 Windows 窗口操作：找到这个群的**单独聊天窗口**（标题就是群名）→ 切到前台 → 点一下输入框 → 剪贴板粘贴 → 回车 → 把前台还给你原来的窗口。发完去库里核对：**看到自己刚发的那条才算发出去** | 不依赖界面控件树，界面改版影响小 |
| **@ / 引用 / 拍一拍 / 进群** | 从库里的 `atuserlist`、引用消息的 `refermsg`、拍一拍的系统消息、群成员表的变化读出来 | — |

几条保护：两条消息之间至少隔 1.2 秒、每小时最多 80 条（防风控，可调）；你正在用键盘鼠标时她先等你停手再发（等 60 秒你还在用，这次就不发了）；每次按键前都确认前台还是微信那个窗口，不是就放弃（绝不把字打进别的程序）；剪贴板里原来的东西（文字、图片、复制的文件）发完原样放回；只认群的单独窗口（标题就是群名），和别的会话同名的群不发，保证不会发错群。

**微信这一头做不到的**：@ 人是普通文字“@名字”（对方不会收到 @ 提醒）；不能引用回复；不能给消息点表情、不能拍一拍回去、不能改签名、没有 AI 语音、暂时听不了语音。群里的图片会解开来给看图模型看（13.1 起）；表情包能认、能存、能发（以图片形式）。提示词里也不会让她选“点表情”。

参考过的项目：[wechatauto-replica](https://github.com/Xpercent/wechatauto-replica)（Apache-2.0，Config.Cipher 密钥结构、WAL 帧盐校验的思路）、[pywechat](https://github.com/Hello-Mr-Crab/pywechat)、[WeChat-Keyword-Bot](https://github.com/wjjiuci/WeChat-Keyword-Bot)（只让一个线程碰界面）、[wechat-automation-api](https://github.com/LAVARONG/wechat-automation-api)。

## 她在群里是什么样

| | |
| --- | --- |
| 🙋 **什么时候说话** | 被 @、被引用回复、被叫名字、被拍一拍一定会回；别的时候看这一批消息的特征算一个“想说的概率”：有人在问问题、聊到她感兴趣的、正在和她聊的人又开口了会更想说；别人在互相 @、她在上课、她刚说了很多（精力低）会不太想说。概率要过“1 小时发言配额”算出来的阈值才开口，她说多了阈值自动收紧；连着几次想了想没说，就先歇一会儿再看。每次判断都记下来，以后可以用自己群的数据重新调 |

| 📈 **知道自己说得好不好** | 她说完 5 分钟内有没有人回复她、@她、她接话的那个人有没有回、大家是不是接着这个话题说，算成“接话率”显示在小屋概览里 |

| 🌙 **半夜不回** | 免打扰时段被叫到先不回，第二天早上醒了补一句“才看到” |
| 🔁 **群里的习惯** | 两个以上的人在复读同一句短话时，她偶尔也跟一句；新人进群欢迎一下；被拍一拍会回应；会用微信的小表情（[捂脸] [旺柴]） |
| 🧑‍🤝‍🧑 **心里有每个人的样子** | 每个群友说了一阵子话，她就给这个人画一张“画像”：大家怎么叫他、性格、说话风格（爱发表情包、句尾爱加“捏”）、口头禅、兴趣、最近在忙什么（带日期）、他和群里谁要好 / 常互损、你们怎么相处、跟他怎么聊他会高兴、哪些话题别碰、记得的小事（带日期）；画像不只看他自己说的话，还看他接的是谁的话、别人怎么说他；每天还会把这一周话最多的几个人仔细回想一遍；再加上她自己算的熟悉度（看他多常找她）和他常在什么时候出现。对谁说话就照着谁来：很熟的互损，刚认识的客气点，接他的梗、关心他的近况。在小屋的“群友”页能看到、也能手动改她心里每个人的样子 |
| 🧠 **记得住** | 这个群最近的事和梗、不成文的规矩（“大家都不 @人”），她自己在群里说过的事；还会记下具体的事（谁在准备答辩、约了周六看展），新说法推翻旧的时旧的标成过时。聊到相关的话题，她会想起很久以前群里说过的话（按关键词在本群的聊天记录里找，不会跨群）。在 A 群知道的事不会在 B 群说 |
| 📰 **群日报 · 回放** | 每天早上整理前一天的群日报（多少人说话、谁最活跃、几件好笑的事、她说完有没有人接）；每次“想说什么”都存一份，`python run.py replay` 可以拿最近 7 天的记录回放，看改了设置以后她会怎么判断；攒够 500 次带接话效果的判断后，每晚用自己群的数据重新拟合“想不想说”的权重 |
| 🎭 **群梗、心情、节奏** | 群梗词条：聊到关键词才告诉她这个梗的意思，提过以后一阵子不再提（照 SillyTavern 的 Lorebook 做的，治老梗反复说；整理群聊时自动加，小屋里也能手写）。心情会持续一阵子：被夸了得意、被怼了不服、说话没人理有点没劲，两小时左右慢慢平复。她“看到消息”要多久按你们群群友自己的回复间隔来 |

| 🧪 **越用越准** | 小屋“帮她挑一句”：她给出两种说法时你挑一个，用来训练一个“AI 腔检测器”（纯 Python 的字 n-gram 分类器，每晚用群友原话 vs 她的话重训，准确率够了才启用）；每晚用接话效果重新拟合“想不想说”（标准化 + 留出验证，比原来好才换）；`python run.py calibrate` 看质检会不会误伤群友的正常聊天；`python run.py replay --judge 20` 让大模型按扣分制找她的毛病 |

| 💬 **冒泡** | 群里安静三小时以上，她可能自己说一句，分享今天的事或者接着之前的话题；最后一句就是她说的就不自言自语 |
| 🚫 **不重复自己** | 和她最近在群里说过的话太像的那条不发 |
| 📥 **不在时的事也知道** | 程序没开、电脑关机、微信没开的时候群里说的话都在微信的本地库里：接上以后直接从库里补进聊天记录（每个群最多 200 条），期间有人 @ 她，等会儿补一句“才看到”。微信刚开时同步下来的离线消息不会一条条去接；你用她的号在手机上说的话，她也知道是“自己说过的” |

## 进群前先认识大家

`scripts\onboard.bat`（或 `python run.py onboard`）：导出群里以前的聊天记录（从电脑上开着的某个号读，一般选你的大号）→ 用大模型整理成
`home/wechat/data/seed_draft.yaml`（群在聊什么、规矩、群梗、每个常说话的人的画像）→ 你看一遍、改一改 → 灌给她。
三步也能分开跑：`wxexport` → `seedgen [导出目录]` → `seed data/seed_draft.yaml`。草稿的格式和手写的种子一样（见 `aigroup/seed.py` 开头的说明），
想自己补充谁就直接改这个文件。灌进去的人算“事先听说的”：真正和她说上几句话以前，她不会把听来的近况、私事说出来。

## 人设

她是谁由你来定：人设是 `home/wechat/persona/` 里的一个 Markdown 文件（不会进 git）。第一次跑 `setup.bat` 时会从 `persona/template.md`（一个写好的示例角色）复制一份过去，你把它改成自己的角色。写法见 [PERSONA.md](PERSONA.md)。

她每天会按人设排一份自己的安排（比如“09:40-11:50 素描课”），群里聊起来前后一致，忙的时候回得慢。

## 配置

`setup.bat` 写的 `home/wechat/config.yaml` 只包含和默认值不一样的项；想调别的，从 `config.wechat.example.yaml` 里抄过来改。密钥都在 `.env` 里（**别发给别人**）。群聊的设置在 `wechat.group` 下：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `talkativeness` | 0.3 | 话痨度：最近 1 小时里留给她的发言份额，她说多了自动收紧（被叫到不受影响） |
| `max_per_10min` | 6 | 每个群 10 分钟最多说几轮（被叫到时放宽到两倍） |
| `read_delay` / `busy_delay_minutes` | [2, 12] 秒 / [1, 2] 分钟 | 被叫到后多久回（她有空 / 她在忙） |
| `instant` | true | 看到就回：不装作没看到、不模拟打字（23.0）；关掉才用 `read_delay` 这些等待 |
| `pace` | 1.0 | 所有等待时间的倍数（`instant: false` 时才有用） |
| `repeat_chance` / `welcome_chance` | 0.5 / 0.7 | 跟着复读 / 欢迎新人的概率 |
| `idle_hours` / `active_hours` | 3 / 10:00-23:30 | 群里安静多久她可能冒泡 / 只在这段时间冒泡 |
| `profile_every` | 15 | 某个人又说了这么多句，就更新一次她心里这个人的画像 |
| `profile_deep` / `profile_deep_people` | true / 5 | 每天一次，这一周说话最多的几个人拿一周的话把画像从头梳理一遍 |
| `learn` / `plan_json` | true / true | 跟着群里学说话方式和黑话 / 先想再说（先选回哪条、说多长，再写正文） |
| `talk_curve` | 上午 0.8 · 中午 1.1 · 下午 0.9 · 晚上 1.2 | 按时段调话量（乘在话痨度上） |
| `quality_check` / `candidates` | true / 2 | 发之前检查 / 让大模型多写几种说法挑一条 |
| `typo_rate` | 0.03 | 偶尔打错一个字 |
| `stickers` / `memory_recall` | true / true | 存表情包、偶尔发 / 聊到了想起以前群里的事 |
| `lore` / `mood` / `human_latency` | true / true / true | 群梗词条 / 持续的心情 / 按群友自己的回复间隔回 |
| `catch_up` / `catch_up_count` | true / 200 | 接上微信后从本地库补上她不在时群里的消息、每个群往回补多少条 |
| `people_aliases` | {} | 群友的别名（真名、外号），`"群名片或微信昵称": "别名、别名"`；也可以在小屋“群里的人”里填 |
| `memory_embed_model` | 空 | 想要语义召回就填一个向量模型（要装 sentence-transformers，比如 `BAAI/bge-small-zh-v1.5`） |

顶层的 `quiet_hours` 是她的睡觉时间（微信版默认不设，24 小时都会回；写成比如 "01:30-09:00" 她就会在这段时间只记下谁叫了她，醒了再回）。

`wechat:` 下面是微信接入本身的设置（一般不用改）：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `send_key` | enter | 微信里“发送”是哪个键（设置 → 快捷键；是 Ctrl+Enter 的话改成 `ctrl+enter`） |
| `search_fallback` | false | 群没有单独窗口时用 Ctrl+F 搜群名打开（默认关：核对不了打开的是不是那个群；打开了也只要一次没核对上就停用） |
| `send_gap_seconds` / `max_sends_per_hour` | 1.2 / 80 | 两条消息至少隔多久 / 每小时最多发多少条（防风控） |
| `idle_seconds` / `max_idle_wait` | 2 / 60 | 你在用键盘鼠标时先等你停手（等这么久还在用就这次不发） |
| `stale_seconds` | 600 | 比这还旧的“新消息”（微信刚开同步下来的）不一条条接，补进记录就好 |
| `confirm_seconds` | 10 | 发完在库里等多久看到自己那条 |
| `data_dir` / `account` | 空 | 微信数据目录 / 用哪个账号（自动找；setup 会写账号） |

### 大模型接口

程序里不带任何接口，要用你自己的。配置向导最后一步会让你加一个；之后要加、要换，双击 **`scripts\llm.bat`**，或者在小屋的“大模型”页：填接口地址（任何 OpenAI 兼容的）和 Key → 自动测连通、列出这个接口的模型 → 选一个 → 试聊一句看看速度 → 选它当主力、当备用，还是只干后台的活。推理模型回复是空的时候会自动试着关掉“思考”。

加的接口写在 `config.llm.yaml`（Key 在 `.env`），不动你的 `config.yaml`。`scripts\llm.bat` 里还能把所有接口试一遍、删掉自己加的接口。

手动写也行：`llm.profiles` 是各个接口，`llm.routes.chat` 是群里说话按顺序用哪些（限流自动换下一个），也可以直接用 `python run.py llm` 加。

## 常见问题

<details>
<summary><b>她不说话</b></summary>

双击 `scripts\check.bat` 看哪一项是 ❌；再双击 `scripts\wxdiag.bat`（或 `python run.py wxdiag`）。常见原因：微信没开 / 没登录她的小号；密钥没拿到（`wxkeys --deep`）；屏幕锁了；大模型 Key 填错或者限流。日志在 `home/wechat/data/logs/group.log`。

</details>

<details>
<summary><b>收得到、发不出去</b></summary>

日志里会写原因：“没找到单独窗口”（在微信里双击这个群）、“前台被别的窗口抢走了”“你一直在用键盘鼠标”（下次会等你停手）、“屏幕锁着”、“没看到刚发的消息”（看看微信设置里发送键是不是 Ctrl+Enter，是的话在 config.yaml 写 `wechat: {send_key: ctrl+enter}`）。“和别的会话同名”（给群改个名字）。

</details>

<details>
<summary><b>微信更新了</b></summary>

一般什么都不用做：密钥存在 `home/wechat/data/wechat/keys.json` 里，更新不会换。偶尔微信新建了消息分片（`message_1.db`），程序会自动去找它的密钥；找不到时日志会提示跑 `python run.py wxkeys --deep`。

</details>

<details>
<summary><b>她发消息时会抢我的键盘吗</b></summary>

发一条大概 1~2 秒：短暂切到微信窗口、粘贴、回车，再切回你原来的窗口。你最近 2 秒内在动键盘鼠标的话她会先等你停手（`idle_seconds`）。如果你经常用这台电脑，建议给她一台单独的电脑或虚拟机。

</details>

<details>
<summary><b>掉线了（小屋显示“微信没接上 / 微信没在运行”）</b></summary>

- **“微信没在运行”**：把微信打开、登录她的小号就行，程序每 30 秒看一次，开回来自动接上，再补上这段时间群里的话。
- **“微信没接上”，后面带了原因**：照原因处理；把鼠标停在红色标签上能看到完整原因。最常见的是密钥没拿到（跑 `python run.py wxkeys --deep`）和屏幕锁了（锁屏时只能收、不能发）。
- **看不出原因**：双击 `scripts\wxdiag.bat`，哪一项是 ❌ 就是哪里断了；日志在 `home/wechat/data/logs/group.log`。
- **都正常还是不行**：托盘图标右键 → 重启。

</details>

<details>
<summary><b>微信关了 / 重启了 / 电脑关机了</b></summary>

微信关掉时她先不说话（小屋显示“微信没在运行”），微信开回来自动接上，再从本地库补上这段时间群里的话。程序和电脑关机期间的消息也一样：下次启动后补上（每个群最多 200 条），期间 @ 她的会补一句“才看到”。

</details>

## 隐私

- 13.0：入库即脱敏（手机号、证件号、卡号、验证码、邮箱）、带聊天正文的日志不进控制台、`keep_days`、
  `python run.py forget-group 群id` / `forget-person 编号` 彻底删除。
- 群里的图片（微信 4.x 本地加密的 .dat）在本机解开后给看图模型看；语音还听不了。

- 程序和数据（群聊记录、对群友的印象、数据库密钥）都在你自己的电脑上：`home/wechat/data/`、`config.yaml`、`.env` 都在 `.gitignore` 里。解密出来的库副本在 `home/wechat/data/wechat/cache/`，只有白名单里的群会被读出来给她看。
- 发给大模型的只有拼提示词需要的那部分：人设、最近的群聊、她对群友的印象和画像。
- 只在白名单里的群说话。
