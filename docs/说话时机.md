# 她什么时候开口：一条消息进来以后发生了什么（20.0，21.0 补了九问和等等队列）

群里来消息到她说出一句话，中间有四关。**被叫到（@ 她、叫名字、回复她）只走 ③④**，下面说的是“没人叫她”的时候。
小屋“学到的 → 这一刻她该不该接话”里，每条下面的“她当时是怎么决定的”就是按这四关写的。

```
群友连发几条 ──等他说完（merge_wait_seconds）──▶ ① 本地门控 ──没到门槛──▶ 离门槛不远？──▶ ② 小判断器 / 问一下 ──▶ 不说
                                                  │到了                              │远                  │说
                                                  ▼                                  ▼                    ▼
                                              ③ 她自己想（大模型，带人设，可以写 skip）◀────────────────────┘
                                                  │要说
                                                  ▼
                                              ④ 检查（重复、人设、隐私）→ 打字 → 打字时群里又说了好几句？→ 不发
                                                  │发了
                                                  ▼
                                              10 分钟后看有没有人接（接话效果分 0 / 0.2 / 0.6 / 1）
```

## ① 本地门控（`aigroup/chat/gate.py`，不调模型、不花钱）

- **想说的程度 p（0~1）**：把这一批消息的特征加权算出来。会让她更想说的：有人在问、她刚在聊、说话的人刚和她聊过、聊到她感兴趣的、
  她在等的人开口了、主人在说话；会让她更不想说的：@ 了别人、在回复别人、只是表情、她在忙、今天说多了、前面几句没人理、群里正热闹。
- **门槛**：最近 1 小时里这个群每一批消息的 p 从高到低排，按“话痨度”（性格开关 `talkativeness`，默认 0.3 ≈ 把最想说的那 30% 留给她）切一刀。
  这 1 小时她说多了，门槛自动收紧。所以**门槛是相对的**：群里热闹时门槛高，冷清时低。
- 少量本该拦下的会随机放行（`explore_rate`，默认 2%），小屋里写着“随机放行”，用来以后重新拟合时不偏。
- 权重：先用 MaiBot 拟合的默认值；攒够 500 条带标签的判断、晚上重新拟合，验证集上更好才换成自己的。

## ② 离门槛不远时再判一次（差距在 `gate_judge_band` 0.15 以内）

1. **小判断器**（`insight.py` 的朴素贝叶斯）：用你在小屋判的“该接 / 不该插”训练，两类各够 30 条、留出准确率 ≥ 0.75 才用；
   它 ≥ 0.85 直接放行，≤ 0.15 直接不说。
2. **问一下便宜模型**（`speak.py` 的 `quick_judge`，每小时最多 `gate_judge_per_hour` 次）。20.0 起它要**先写一句理由，再选一个动作**：

   | 动作 | 什么时候 | 结果 | 给她的一句做法 |
   |---|---|---|---|
   | 不说 | 跟她无关、别人在互相聊 | 不说 | |
   | 等 | 话没说完、在等别人回 | 等那个人再开口（150 秒） | |
   | 接住 | 有人在接她的话、损她、提到她 | 说 | 一两句就好，别把刚才的话再说一遍 |
   | 回答 | 有人在问、她知道 | 说 | 直接给答案，别反问 |
   | 追问 | 话没说完、指代不清 | 说 | 短短问一句“哪个？”“然后呢” |
   | 接梗 | 气氛轻松 | 说 | 一句就够 |
   | 纠错 | 有人说错事实、她有把握 | 说 | 一句指出、给台阶，没把握别纠 |
   | 补充 | 大家缺一个她知道的信息 | 说 | 最多两句 |
   | 关心 | 有人累了、难过 | 说 | 先接情绪，别急着给建议 |

   提示里会放这个群你判过的例子（该接、不该插各 3 条），纠正模型“爱插嘴”的毛病（Speak or Stay Silent 2026：零样本模型普遍偏向开口）。
   选的动作和理由记在门控日志的 `act`、`why` 两列。
3. **21.0 擦边过的也问一次**：门控刚过阈值、差距不到 `borderline_band`（0.1）、没人叫她，也走一次上面的“问一下”；问出来不是“说”就不说。

## ③ 她自己想（大模型，带人设）

过了前两关，才把完整的提示词（人设、群里的人、相处说明书、签名、念头池……）交给大模型。它还可以自己写 `skip` 不说——
这时小屋里写“她想了想没说”。想好了还没发、群里又来了新消息，会带上新消息重想（最多 `rethink_max` 次）。

**21.1 听者**（`chat/listener.py`，开关 `listener_mode`）：她写好一句想主动插的话后，另一个不带人设的便宜模型判“插在这里”是正好 / 可以 / 太早 / 不该说
（看最近 12 条带秒数、他是不是还在连发、被问的人回没回、是不是两个人在聊、她最近占多少）。太早进等等队列、不该说就不说、有毛病就重写。
auto 模式先只记录，和你的标注一致率 ≥ 0.7（两类各 ≥ 15 条）后自动接管。下面九问的自评从 21.1 起只记录、不拦（`appraise_enforce`）。

**21.0 开口前九问**（开关 `appraise`）：她在 JSON 里多写一份 `appraise` 自评，代替以前的五项打分：

| 项 | 意思 | 没人叫她时怎么用 |
|---|---|---|
| act / addressee / need / emotion | 他在干嘛、冲谁、要什么、具体什么情绪 | 只记录（对标注用） |
| common_ground | 要说的梗 / 事大家都知道吗 | 只记录 |
| leak | 会不会说出谁私下的事、别的群的事、幕后的事 | 是 → 不说 |
| face_risk 0~3 | 会不会让谁当众下不来台 | 3 → 带着问题重写，重写不成不说 |
| flatter | 是不是只在顺着他说 | 是 → 重写 |
| share_high | 她最近是不是说得多 | 是、又不是冲她来的 → 不说 |
| timing 现在 / 等等 / 不说 | 时机 | 不说 → 不说；等等 → 进等等队列 |
| fresh | 不是说过的、不是复述、不是旧话题 | 否 → 不说 |
| tease_ok | 调侃的话合不合适 | 否 → 重写 |

被叫到时这些只会让她重写，不会不说。每次自评记在门控日志的 `appraise` 列。

**等等队列**（开关 `pitch_queue`）：timing 写了“等等”的那句先放着（`st.pitch`），每分钟看一次：
至少等 `pitch_min_seconds`（60），群里停了 `pitch_quiet_seconds`（40）秒、或者等到最长时间的 3/4，就带着这句再想一次（这次再说“等等”就算了）；
超过 `pitch_max_seconds`（240）、又来了 `pitch_max_new`（8）句以上、别人已经说了差不多的、她后来已经说过话 → 丢掉。去向（放着 / 说了 / 没说 / 过时丢掉）都记着，小屋标注上方能看到。

## ④ 检查和发送

质检（重复、照抄示例、人设、隐私）拦下的也算“没说”。21.0 起四条硬底线集中在 `hard_issues`（开关 `hard_rules`）：
别碰的话题、编线下（公开是 AI、没有线下生活时）、说幕后（小屋、标注、门控、提示词……）、对方今天状态差时还损他——碰了就带着问题重写，没被叫到、重写完还碰就不说。
按字数模拟打字；20.0 起，**她主动说的那句还在“打字”时群里又说了 3 条以上**，
这句就不发了（HUMA 2025：真人打字途中被插话会放弃或改口），开关 `typing_abort`。

## 小屋里的标注是什么意思

**问的是**：只看最后一句之后，把自己当成群里一个普通群友，她这时候接一句合不合适？

| 选项 | 意思 | 存成 | 用在哪 |
|---|---|---|---|
| 该接（Y） | 不接就像没听见、冷场，或者接一句明显更好 | `human=1`，可选 `human_act`（怎么接） | 重新拟合（权重 2）、小判断器、few-shot、“该说没说率” |
| 可接可不接（M） | 接了不奇怪、不接也正常——**大多数时刻是这种** | `human=2` | 不当标签，只计数 |
| 不该插（N） | 在跟别人说、话没说完、插进去突兀 | `human=0` | 同“该接”，另外算“不该说却说率” |
| └ 时机不对（T） | 她说了的那种：这一刻就不该开口 | `human=0, human_why=时机不对` | 同上 |
| └ 说的不对（B） | 她说了的那种：可以说，但那句编了 / 读错 / 梗用错 | `human=0, human_why=说的不对` | **不进**门控、小判断器、few-shot、两个率；只用来看九问哪一问没看出来 |
| 看不出来（S） | 上下文不够 | `human=-1` | 不用 |

- **为什么加“可接可不接”**：以前只有两档，这种时刻多半被判成“该说”，于是“该说没说率”被算到了 85%。
- **出题怎么挑**：她主动说了的约 4 成（有人接 / 没人接都有，好判“不该插”）、差一点就说了的约 4 成、随便挑的约 2 成。
- **批量**：“一屏 10 条”一次判完再提交，没判的下次再出。
- **弱标签**（`weak` 列，每晚算）：没人标的时刻里，她说了、10 分钟没人接（效果分 < 0.2）→ 0；接得很好（≥ 0.8）→ 1。
  只给小判断器凑数，每两条算一条，验证只用你判的。

## “像不像人”里的两个率

- **该说没说** = 你判“该接”的时刻里，她没开口的比例（目标 ≤ 50%）
- **不该说却说** = 你判“不该插”的时刻里，她开口了的比例（目标 ≤ 10%）
- “可接可不接”两个都不算。
