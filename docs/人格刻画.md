# 人格刻画：怎么让她像一个人，又怎么让她懂每一个人

这份文档讲群里的她（`aigroup`）是怎么被“刻画”出来的：她自己的人格怎么写、怎么在每一句话里起作用、怎么慢慢长、怎么检查有没有走样；
以及她怎么用同一套办法去理解群里的每一个人。代码在 `aigroup/traits.py`、`aigroup/chat/prompt.py`、`aigroup/memory/`、`aigroup/eval/traits.py`。

> 一句话：**形容词不是人格。** “嘴贫、傲娇、心软”这种写法，模型会执行过头（被逗时回个不停、毒舌变刻薄），长对话里还会被稀释。
> 所以这里把人格拆成能执行、能检查、能慢慢长的几层，每一层用心理学里有实证基础的模型来写。

## 1. 依据

| 来源 | 说的是什么 | 在这里用来做什么 |
| --- | --- | --- |
| 大五人格 + 30 个 facet（NEO-PI-R / [IPIP-NEO](https://ipip.ori.org/)） | 五个维度各分 6 个细项 | 写一张“特质剖面”：只写和她有关的十来项，每项 1~5 档 + 一句说明 |
| [HEXACO](https://hexaco.org/) 的诚实-谦逊 | 不操纵、不讨好 | 底线：不撒娇要互动，不拿情绪绑架人 |
| CAPS（[Mischel & Shoda 1995](https://doi.org/10.1037/0033-295X.102.2.246)） | 人格稳定在“如果……就……”的情境签名上，不在平均值上 | 每个特质写成 if-then：什么时候、她会怎样、她不会怎样 |
| McAdams 三层（[2006](https://doi.org/10.1037/0003-066X.61.3.204)） | 特质 / 目标与应对 / 叙事身份 | 分层管理：特质只有人能改，自省只写后两层 |
| 幽默风格（[Martin 2003](https://doi.org/10.1016/S0092-6566(02)00534-2)） | 亲和、自我提升、攻击、自贬 | 毒舌按配比写：亲和为主、调侃有节制、攻击型接近 0 |
| [Schwartz 价值](https://doi.org/10.9707/2307-0919.1116) | 价值之间有相容也有冲突 | 一张价值排序表，规则冲突时按它裁决 |
| 依恋（焦虑 × 回避）、人际环形（支配 × 温暖） | 关系里的位置 | 被冷落时怎么做；她在群里是“损友”还是“姐姐” |
| [Persona Drift（Li 2024）](https://arxiv.org/html/2402.10962v1) | 人设 8 轮内就开始漂，越聊越像对方 | 核心写短，离生成最近的地方放当轮提醒 |
| [CharacterEval](https://arxiv.org/abs/2401.01275)、[Serapio-García 2023](https://arxiv.org/pdf/2307.00184) | 角色评测维度；用量表给模型文本打人格分 | 每周人格一致性检查 |
| [Generative Agents](https://arxiv.org/abs/2304.03442) | 反思要引用具体记忆 | 每月自省必须带证据 |

MBTI 重测稳定性差，只适合当角色自称的梗，不拿来当生成依据。

## 2. 六层结构

| 层 | 写什么 | 放在哪 | 谁能改 |
| --- | --- | --- | --- |
| 1 核心身份 | 一两句：她是谁、和这个群什么关系 | 人设开头 + `traits.core` | 你 |
| 2 特质剖面 | facet 档位 + 说明 | `traits.facets` | 你（她只能提建议） |
| 3 情境签名 | when / do / not | `traits.signatures` | 你 |
| 4 价值与动机 | 价值排序、想要 / 需要 / 毛病 / 矛盾、依恋、幽默配比 | `traits.values` 等 | 你 |
| 5 声音 | 句长、口头禅配额、不说的话、对话示例 | `traits.voice` + 人设的“# 对话示例” | 你 |
| 5′ 知识边界（15.0） | 熟的 / 只知道个大概 / 不懂 / 不感兴趣 | `traits.knowledge` | 你 |
| 6 叙事身份 | 这一阵在意什么、怎么应对、一个关键场景、故事往哪走 | 每周“这一周的我”、每月“我是怎样的人” | 她自己写，要有证据 |
| 状态 | 心情（一句话 + 原因，不给数值）、和每个人的熟悉度、今天的安排 | 每轮提示词 | 程序 |

## 3. 人格文件怎么写

人设文件顶部加一行 `traits: xxx.traits.yaml`，把人格文件放在同一个文件夹。完整示例：[`persona/traits.example.yaml`](../persona/traits.example.yaml)。

```yaml
core: 你是群里的一个嘴贫、记性好、护短的朋友。
values:                      # 冲突时从上往下裁决
  - 不让任何人在群里真的难堪
  - 诚实：不装懂、不编
  - 好玩
facets:                      # N1~C6，1 很低 … 5 很高
  A2: {level: 4, note: 说话直，不懂就说不懂}
  A4: {level: 2, note: 被怼先呛回一句，但真错了就认}
  A6: {level: 4, note: 见人真难过立刻软下来}
humor:
  mix: {亲和: 50, 调侃: 30, 自嘲: 20, 攻击: 0}
  never: [外貌身材, 家里, 钱, 感情]
  repair: 被损的人没接梗就先补台，别再加码
signatures:
  - id: sad
    when: 有人累了、难受
    flags: [sad]             # 程序认出来的情境
    keys: [崩溃了]           # 触发词
    do: 立刻不贫了，先接住他说的事，问一句要不要说说
    not: 这时候损他、讲大道理
```

几个要点：

- **“毒舌”要拆开写。** 坦率高 + 顺从低 + 温柔高 = 嘴上不让人、心里软；只写“宜人性低”会被演成刻薄。
- **每条签名都写“不会”。** 反例比正例更能挡住模型的惯性（比如“被连着逗：不会追问第二遍”）。
- **签名写具体场合，别写口号。** “有人问吃什么：直接给一个答案带一句理由”比“乐于助人”有用得多。
- `python run.py qq check`（体检）会报出写错的 facet 代号、比例加起来不是 100、不认识的情境名。

## 4. 运行时：每一句话里人格怎么起作用

1. **静态部分**：人格文件渲染成一段“# 你的人格”，接在人设正文最前面（system 里，稳定、命中缓存）。
2. **认出情境**：程序看这一批消息和自己的状态，认出 13 种情境——被叫到、被同一个人连着叫、她刚才的话没人接、被夸、被损、有人难过、问推荐、有人鸽了、被纠正、深夜、想冒泡、新人、在聊 AI。
3. **挑签名和示例**：情境命中一个算 2 分、触发词命中一个算 1 分，取前 3 条签名；再按触发词挑 1~2 段人设里的对话示例。
   这两样放在提示词**最后**（“# 此刻”之后、锚点之前），离生成最近，对抗人设漂移；不命中就不加，提示词不会变长。
4. **先读懂对方**：输出格式里的 `think` 先判断对方这句想要什么（逗你 / 认真问 / 求安慰 / 分享 / 吐槽 / 随口一说），再决定怎么回。
5. **发之前检查**：AI 腔、越界、和刚说过的太像的不发；被连着逗时最多一条，可以不回。
6. **想法池**（15.0，参考 [Inner Thoughts](https://arxiv.org/abs/2501.00383)）：想说但时机不对的一句写进 `hold` 留着，
   聊到相关的或群冷了再拿出来给她考虑，说出口就划掉。插话前心里过一遍八件事：相关、补信息、影响、急不急、接得上、新意、是不是说太多、节奏。
7. **签名效果**（15.0）：每次用了哪几条签名都记下来，小屋显示近两周每条签名用上以后有没有人接。

8. **心情改变反应**（16.0）：她自己的心情认出“有点不服气 / 有点低落 / 心情很好”，人格文件可以给这三种状态写签名
   （`flags: [mood_annoyed]`、`mood_down`、`mood_high`）。这是 CAPS 原本的意思：if 情境 *且* 内部状态 then 行为。
9. **签名改写建议**（16.0）：常冷场的签名每周自动变成一条改写建议，等你决定。

开关（小屋“性格开关”页）：`signatures`、`signature_k`、`persona_examples`、`example_k`。

## 5. 她怎么理解每一个人

同一套心理学也用来理解群友。每个人的画像有 14 个字段，按 McAdams 三层看：

| 层 | 字段 |
| --- | --- |
| 特质 | 性格、说话风格、口头禅 |
| 情境签名 | **他的反应**：“被损时……；累了时……；兴奋时……”，只写见过的 |
| 动机 | **在意**：他在群里图什么（被认可、有人接梗、有人陪着吐槽、安静看着） |
| 价值和看法 | 看法、兴趣 |
| 当下和故事 | 近况（带日期）、记得的事 |
| 关系 | 称呼、群里关系、和你、怎么聊、别碰 |

怎么来的、怎么用：

- **进群前“认识大家”**（`onboard`）：把以前的聊天记录整理成画像草稿，你看过、删掉不想让她知道的，再灌给她。灌进去的算“事先听说的”，真正说上话以前她不会把听来的私事说出来。
- **每晚整理**：某人又说了一定数量的话就重写他的画像；每天挑最活跃的几个人从头梳理一遍。只写有证据的，别人损他的话不当成他的性格。画像有历史版本，小屋里能看、能改、能退回。
- **熟悉度**：刚认识 / 挺熟 / 很熟，看他找她的次数和活跃度。刚认识的人她先客气、不翻旧账。
- **别碰**：每个人的“别碰”话题在发之前的检查里会被拦下来。
- **此刻的心思**：画像是长期的，`think` 里对这一句的判断是当下的，两者一起决定她接哪条签名。
- **今天的他**（15.0）：从他今天说过的话里看出“状态不太好 / 在忙 / 心情不错”，放进当轮提示；状态不好时自动带上“有人难过”的签名。
- **谁说的、到哪天为止**（15.0）：记下的每件事带来源（他自己说的 / 听别人说的 / 猜的）和有效期；
  玩笑、互损、转述别人的事不算到他头上（[PersonaMem-v2](https://arxiv.org/abs/2512.06688) 发现模型很难分清别人的事和本人的事）。
- **关系网**（16.0）：数两周里谁回复谁、谁 @ 谁、谁紧接着谁说话，知道“谁和谁常聊”。
- **相处经验**（16.0）：她对某人说过的话哪些被接、哪些冷场，每晚总结成 3~5 条“他吃哪一套”，和他说话时提醒她。
- **谁刚回来**（16.0）：隔了几小时又出现的人，提示她“他不在时群里聊了这些，别默认他看过”（对应 FANToM 的“谁知道什么”）。
- **今天的状态由模型判断**（16.0）：关键词只是触发，真正的判断交给便宜模型读他今天的话，分得清玩笑和真的累。
- **画像抽查**（16.0）：你在小屋给画像字段点“对 / 不对”，统计准确率；标错的字段下次按证据重写。
- **猜的要两次证据**（16.0）：“你猜的”事出现第二次才用，他自己说了就升级。
- **隐私边界**：入库前脱敏（手机号、证件号、卡号、验证码、邮箱），不记住址、真名全称、身体、钱、感情这类；私下说的、别的群听到的，不在这个群说；可以“忘掉某人 / 某个群”。

## 6. 成长与审核

| 什么时候 | 她做什么 | 能改哪层 |
| --- | --- | --- |
| 每天 | 重新整理群友画像 | 画像（有历史版本） |
| 每周一 | “这一周的我” 3~5 句 | 第 6 层（短期） |
| 每月初 | “我是怎样的人”：在意什么、怎么应对、一个带日期的关键场景、故事往哪走，每条要有证据 | 第 6 层 |
| 每月初 | 觉得某个 facet 该改一档时提建议（最多 2 条） | 只记成建议 |
| 你在小屋 | “她的日子 → 她是怎样的人”下面采纳 / 不改 | 采纳后你去改人格文件，重启生效 |

人设或人格文件一改，启动时会记一个新版本，下一次每周评测会拿同一段真实聊天让新旧两版各生成一次，盲比哪句更像真朋友。

## 7. 评测：她有没有走样

每周一自动跑，结果在小屋“性格开关”页：

- **扣分制评测**：挑 10 句她说的话找毛病（答非所问、人设不符、AI 腔、越界……）。
- **人格一致性**：评测模型**不看人设**，只读她这一周说的话，给人格文件里的每个 facet 打 1~5 分，和目标比平均差几档、哪几项差 2 档以上；
  同时数四种幽默各几句，攻击型的原话抄出来。每一项“高 / 低”的描述是照 IPIP-NEO 各 facet 的意思自己写的中文行为描述。
- **人设盲比**：见上一节。
- **定向测试**（16.0，参考 CharacterBench）：给每条签名、每个“不懂 / 不感兴趣”的话题编一段会触发它的群聊，让她回，
  按那条规则打 1~5 分，同时看程序有没有挑中那条签名。平时很少触发的性格，也能每周测到。
- **说话指纹**：她的句长、标点、表情和群友比。

一周几十句话，单次分数会抖，只看周趋势。
